Observations

In this exercise, the root process initializes an array with values from 1 to 1,000,000 and uses MPI_Bcast to send the complete array to every process. Each process allocates memory for the full array even though it only sums a portion of the elements. When four processes are used, each process sums 250,000 elements. The non-root processes send their local sums to the root using MPI_Send, while the root receives each value separately using MPI_Recv and calculates the final total of 500,000,500,000. All processes must call MPI_Bcast to prevent a deadlock, and the number of processes must evenly divide 1,000,000. Although the program calculates the correct result, this method wastes memory because every process stores the complete array, and the root must collect the partial sums one process at a time.
