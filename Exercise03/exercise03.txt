Observations

In this exercise, MPI_Scatter divides the complete array on the root into equal chunks and sends one chunk to each process. Every process calculates a local sum and then calls MPI_Gather to send that value to the root, where the values are stored in rank order in the all_sums array. This replaces the individual MPI_Send and MPI_Recv operations used in Exercise 2 and makes the result collection simpler. The root still needs to loop through the gathered values and add them together to produce the expected total of 500,000,500,000. Only the root stores the complete input array and the gathered partial sums, while each process stores only its assigned chunk. Although MPI_Gather simplifies communication, it only collects the values and does not perform the final summation automatically.
